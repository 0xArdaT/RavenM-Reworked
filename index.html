Deployment

Installation guide

Four steps, no installers. Follow them in order — step one especially, or the plugin folder won't exist yet.

01

Prepare BepInEx & first launch Required

Extract the BepInEx zip directly into your Ravenfield install folder, then launch the game once and close it again. This lets BepInEx generate its full folder structure — including the plugins folder you'll need in the next step. Skipping this is the #1 reason the mod "doesn't show up."

02

Drop in RavenM.dll

Download RavenM.dll from the Releases page and place it inside your BepInEx plugins folder — directly inside it, not in a subfolder.

Ravenfield/ BepInEx/ plugins/ RavenM.dll
03

Copy the plugins path

Steam's default install path for the plugins folder — click to copy, then paste it straight into Windows Explorer's address bar.

\steamapps\common\Ravenfield\BepInEx\plugins
Relative to your Steam library, e.g. C:\Program Files (x86)\Steam\steamapps\...
04

Verify the install

Launch Ravenfield. If everything's wired up correctly, you'll see RavenM Reworked v.xxx.xx printed in the bottom-left corner of the main menu and in-game.

Not showing up? Make sure RavenM.dll sits directly inside plugins (not a subfolder), and that you completed step 01 — running the game once before copying the file in — so the folder actually exists.
